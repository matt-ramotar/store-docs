## Read resolution

Every data result names the boundary that supplied the value. Origin and freshness are independent:
read `origin` to identify provenance, then read `isStale` and `refreshing` for lifecycle state.

## Modules and targets

API tier and target coverage are separate. Experimental modules can still publish broad target
matrices, while adapter execution depends on the database runtime available on each target.
