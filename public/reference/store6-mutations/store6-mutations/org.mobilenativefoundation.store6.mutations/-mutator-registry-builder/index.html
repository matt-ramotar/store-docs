MutatorRegistryBuilder

@ExperimentalStoreApi
class MutatorRegistryBuilder<K : StoreKey, V : Any>

Registers typed durable mutators.

Every registration is durable and named: no call-site closure becomes a durable intent. Each non-delete mutator supplies an explicit args version and MutationCodec; delete is the one specialization and owns a fixed module-internal version-1 Unit codec encoding zero bytes.
