TransactionalSourceOfTruth

@ExperimentalStoreApi
@SubclassOptInRequired(markerClass = [DelicateStoreApi::class])
interface TransactionalSourceOfTruth<K : StoreKey, V : Any> : SourceOfTruth<K, V>

Optional atomicity capability for a SourceOfTruth. Detectable via sot is TransactionalSourceOfTruth; the engine never assumes it and there is deliberately no silent non-atomic default.
