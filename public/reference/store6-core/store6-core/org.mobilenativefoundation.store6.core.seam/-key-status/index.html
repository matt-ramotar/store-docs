KeyStatus

@ExperimentalStoreApi
class KeyStatus(val meta: StoreMeta?, val lastSuccessSequence: Long?, val lastFailureAtEpochMillis: Long?, val consecutiveFailures: Int, val durablyStale: Boolean)

Immutable bookkeeping state for one canonical key.

durablyStale reflects the exact watermark algebra max(mark/ns/global) > (success ?: 0). A failure-only record therefore reports false until a mark or watermark covers it.
