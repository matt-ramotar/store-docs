fetcherOfResult

fun fetcherOfResult(fetch: suspend (K) -> FetcherResult<V>)

Configures a fetcher that returns the full FetcherResult vocabulary.

The name follows v5's Fetcher.ofResult. The regular-interface fetcher overload cannot accept a lambda, so lambda-return-type inference remains unambiguous. The last registration wins across all three fetcher install points.
