## Owned-output safety

`evidence/T4-owned-targets.json` is the committed census for generated files. Its size is 8,706 bytes and its current SHA-256 is `a64ce5eb2bdcf1eba933237b4859008ce5b6c7563d43dd1b03bbf355dd2bc45a`.

- `port-page:acquire`: one snapshot target
- `port-page:generate`: 38 targets, comprising 37 inventory outputs and the manifest
- `sync-store6-docs`: eleven locked Store6 outputs

Before creating directories, temporary files, backups, or replacements, both generators validate every existing path component from the repository root and reject symlinked ancestors or targets. An existing current output that is absent from every preceding owner census is rejected with `OWNED_TARGET_UNCLAIMED`; generators cannot silently adopt it. A removed inventory or source-lock entry deletes only a regular file whose bytes still match the preceding ledger SHA-256.

The output set and removals are backed up, and successful installation of the new ledger is the transaction commit point. Failures before that rename restore the prior bytes, modes, and ledger. After commit, cleanup attempts every backup removal and the transaction-directory removal. A cleanup failure reports `OWNED_OUTPUT_COMMITTED_CLEANUP_FAILED` without deleting or rolling back the committed files. Rerunning the generator is safe and idempotent, but it does not retry cleanup for the earlier transaction path named by the error. If that path still exists, inspect it and remove its leftovers manually only after confirming they are transaction artifacts.

Existing regular-file modes, including the ledger mode, are preserved. Newly introduced generated text targets default to mode `0644`; the current ledger is also mode `0644`, and none of the owned files is executable. Isolated tests pass for stale removal, modified-stale refusal, unclaimed-target refusal, pre-commit rollback with mode restoration, post-commit cleanup failures after the first backup removal and at final directory removal, and symlinked-parent escape for both owners. The existing T3 Store6 overview and unrelated files are outside both generator-owned sets.
