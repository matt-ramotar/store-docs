Use the exact installed slugger and preserve navigation if optional copy fails. Root accepted this finding; correction/proof pending at report creation.

The summary's external outline (`:44-46`, 2px with 3px offset) may also be clipped at the details edges. Root was asked for anchor-versus-summary rectangles, hash navigation, and a focused screenshot. Position omission is source-confirmed; actual focus failure awaits live confirmation.

3. **P2 — Open package Search shows overlapping input text/icon and truncated result heading.** `screenshots/o2-search-open-1440.png` visibly places entered text under the leading search icon and ellipsizes the deliberately long result heading. Local `components/docs/mintlify/overlays/styles.css:37-40` supplies no input spacing after layer integration; installed Search expects `pl-11/pr-14`. The wrapping rule at `:66-69` is not achieving its declared result in the screenshot. Restore the actual padding and effective wrapping, then verify at narrow and desktop widths. This is observed behavior, not merely missing coverage.

4. **Tooltip acceptance evidence is unresolved.** `browser/o2-gallery-portals.json` records a mounted white/ink popup but `describedBy:null`; its captured popup has neither ID nor role.
